# Sample Audio Files

Put small test audio files here (optional). Keep each file under ~5 MB.

## How to create test audio on Windows
1. Open the **Sound Recorder** (Voice Recorder) app.
2. Record 10-20 seconds of clear English speech (it saves as `.m4a`).
3. Save it here as `clear_english.m4a`.

## Suggested test files
| File name | Description |
|---|---|
| `clear_english.m4a` | Clear speech in a quiet room |
| `noisy_speech.m4a` | Speech with a fan, TV or traffic in the background |
| `fake_audio.mp3` | A text file renamed to `.mp3` (to test the invalid-file error) |
